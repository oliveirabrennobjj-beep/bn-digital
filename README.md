# BN Digital

Site da BN Digital: sites, cardápios digitais e placas NFC para avaliações no Google. Casimiro de Abreu (RJ).

No ar em: https://oliveirabrennobjj-beep.github.io/bn-digital/

Este repositório guarda só a versão pronta do site (build). O código-fonte fica no repositório `Meu-site`, pasta `bn-digital/`: depois de mudar algo lá, rode `npm run build` e copie o conteúdo de `dist/` para cá.
